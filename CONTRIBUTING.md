# Contributing

Repositories in this organisation hold public examples, SDK helpers and integration templates for Sparring (https://sparringhq.com). The Sparring product itself is proprietary and not hosted here.

- Open an issue describing the change before a large pull request.
- Keep examples minimal and runnable: one file per language where possible, environment variables for keys, no secrets in code.
- By contributing you agree your contribution is licensed under the repository's license (MIT unless stated otherwise).
